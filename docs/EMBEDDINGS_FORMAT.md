# ViSpider Embeddings Format

## File: vispider_embeddings.json

### Structure

```json
{
  "model": "text-embedding-3-small",
  "total_samples": 1996,
  "embedding_dimension": 1536,
  "embeddings": [
    {
      "index": 0,
      "en_embedding": [0.123, -0.456, ..., 0.789],  // 1536 dimensions
      "vi_embedding": [0.234, -0.567, ..., 0.890],  // 1536 dimensions
      "similarity": 0.8756
    },
    // ... 1995 more samples
  ]
}
```

### Size Information

- **File size**: ~50-60 MB (JSON format)
- **Memory usage**: ~25 MB when loaded into Python
- **Embedding dimension**: 1536 (text-embedding-3-small)
- **Total vectors**: 3,992 (1,996 pairs)

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `model` | string | OpenAI embedding model used |
| `total_samples` | int | Number of samples (1996) |
| `embedding_dimension` | int | Vector dimension (1536) |
| `embeddings[].index` | int | Sample index (0-1995) |
| `embeddings[].en_embedding` | float[] | English question embedding |
| `embeddings[].vi_embedding` | float[] | Vietnamese question embedding |
| `embeddings[].similarity` | float | Cosine similarity (0-1) |

## Usage Examples

### Load in Python

```python
import json
import numpy as np

# Load embeddings
with open('vispider_embeddings.json', 'r') as f:
    data = json.load(f)

# Get a specific embedding
sample_0_en = np.array(data['embeddings'][0]['en_embedding'])
sample_0_vi = np.array(data['embeddings'][0]['vi_embedding'])

print(f"English embedding shape: {sample_0_en.shape}")  # (1536,)
print(f"Vietnamese embedding shape: {sample_0_vi.shape}")  # (1536,)
```

### Calculate Custom Similarity

```python
from sklearn.metrics.pairwise import cosine_similarity

# Get all English embeddings
en_embeddings = np.array([item['en_embedding'] for item in data['embeddings']])

# Get all Vietnamese embeddings
vi_embeddings = np.array([item['vi_embedding'] for item in data['embeddings']])

# Calculate pairwise similarities
similarities = cosine_similarity(en_embeddings, vi_embeddings)

print(f"Similarity matrix shape: {similarities.shape}")  # (1996, 1996)
```

### Find Nearest Neighbors

```python
from sklearn.neighbors import NearestNeighbors

# Build index on Vietnamese embeddings
nbrs = NearestNeighbors(n_neighbors=5, metric='cosine')
nbrs.fit(vi_embeddings)

# Find 5 nearest neighbors to sample 0
distances, indices = nbrs.kneighbors([vi_embeddings[0]])

print("Nearest neighbors:")
for i, (dist, idx) in enumerate(zip(distances[0], indices[0])):
    similarity = 1 - dist  # Convert distance to similarity
    print(f"{i+1}. Sample {idx}: similarity = {similarity:.4f}")
```

### Export to NumPy

```python
# Save as compressed NumPy arrays
np.savez_compressed(
    'embeddings.npz',
    en=en_embeddings,
    vi=vi_embeddings,
    similarities=np.array([item['similarity'] for item in data['embeddings']])
)

# Load later
loaded = np.load('embeddings.npz')
en = loaded['en']
vi = loaded['vi']
sims = loaded['similarities']
```

## File: embeddings_for_training.npz

Generated by `embeddings_utils.py`, contains:

```python
data = np.load('embeddings_for_training.npz')

# Available arrays
data['en_embeddings']    # (1996, 1536) - English embeddings
data['vi_embeddings']    # (1996, 1536) - Vietnamese embeddings
data['similarities']     # (1996,) - Similarity scores
data['ids']              # (1996,) - Sample IDs (e.g., 'train-0003')
data['db_ids']           # (1996,) - Database IDs
data['model']            # 'text-embedding-3-small'
data['dimension']        # 1536
```

### Use in ML Models

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# Load data
data = np.load('embeddings_for_training.npz')
X = data['vi_embeddings']
y = (data['similarities'] > 0.85).astype(int)  # Binary classification

# Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Train
model = LogisticRegression()
model.fit(X_train, y_train)

# Evaluate
score = model.score(X_test, y_test)
print(f"Accuracy: {score:.4f}")
```

## Performance Notes

### Memory Usage

| File | Size on Disk | RAM Usage | Load Time |
|------|--------------|-----------|-----------|
| vispider_embeddings.json | ~55 MB | ~80 MB | ~2-3 sec |
| embeddings_for_training.npz | ~24 MB | ~25 MB | <1 sec |
| vispider_with_embeddings.json | ~75 MB | ~120 MB | ~3-4 sec |

### Recommendations

- **For ML training**: Use `.npz` format (faster, smaller)
- **For analysis**: Use `vispider_embeddings.json` (easier to inspect)
- **For serving**: Use `.npz` format with lazy loading
- **For exploration**: Use `vispider_with_embeddings.json` (all data in one place)

## Embedding Model Info

### text-embedding-3-small

- **Dimension**: 1536
- **Cost**: $0.00002 per 1K tokens (~$0.04 for full dataset)
- **Max tokens**: 8,191 per request
- **Performance**: Good balance of quality and cost
- **Use case**: Semantic search, clustering, similarity

### Alternative: text-embedding-3-large

If you need higher quality:
- **Dimension**: 3072
- **Cost**: $0.00013 per 1K tokens (~$0.26 for full dataset)
- **Better accuracy** but 2x dimensions and slower

## Data Integrity

### Checksums

After generating embeddings, verify:

```python
import json
import hashlib

with open('vispider_embeddings.json', 'r') as f:
    data = json.load(f)

# Check total samples
assert data['total_samples'] == 1996, "Sample count mismatch"

# Check dimensions
for emb in data['embeddings']:
    assert len(emb['en_embedding']) == 1536, "EN embedding dimension error"
    assert len(emb['vi_embedding']) == 1536, "VI embedding dimension error"
    assert 0 <= emb['similarity'] <= 1, "Similarity out of range"

print("✓ All checks passed")
```
