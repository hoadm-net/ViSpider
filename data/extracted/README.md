# Extracted Spider Data

This folder contains simplified Spider dataset extracted from raw data.

## Purpose

Intermediate step between raw Spider format and translation phases. Raw Spider data is complex with multiple fields. This step extracts only essential fields needed for translation.

## Format

Simplified format with 4 fields only:
```json
{
  "id": "train-0001",
  "db_id": "concert_singer", 
  "question": "How many singers do we have?",
  "query": "SELECT count(*) FROM singer"
}
```

## Files

Generated by `scripts/phase1_prepare/01_extract_spider_data.py`:

- `train.json` - Training set (from `train_spider.json` + `train_others.json`)
- `dev.json` - Development set
- `test.json` - Test set

## Workflow

```
data/raw/              (Spider original format)
    ↓
[Phase 1: Extract]
    ↓
data/extracted/        (Simplified format) ← You are here
    ↓
├─→ Phase 2: Manual translation → data/manual_translations/
├─→ Phase 3: GPT translation → data/chatgpt_translations/
└─→ Phase 4+: Model translation → data/model_translations/
```

## Usage

Source data for:
- Sample selection (choose which examples to translate)
- Phase 1: Manual translation workflow
- Phase 2: GPT few-shot prompting
- Phase 3: Model training and inference
