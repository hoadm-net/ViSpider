# Manual Vietnamese Translations for Spider Dataset

This folder contains 2,000 manually translated samples from the Spider text-to-SQL dataset.

## Files

### `label_studio_2000_samples.json`
- **Source**: Label Studio export from professional human translation project
- **Format**: Label Studio annotation format with metadata
- **Total samples**: 2,000 spider training samples
- **Status**: Raw export from annotation tool

### `vispider_train_2000.json`
- **Source**: Parsed from `label_studio_2000_samples.json`
- **Format**: Clean JSON format for training/evaluation
- **Total samples**: 1,996 successfully parsed samples (99.8% success rate)
- **Status**: Ready for use

### `vispider_embeddings.json`
- **Source**: Generated by `semantic_alignment_analysis.py`
- **Format**: OpenAI embeddings (text-embedding-3-small, 1536 dimensions)
- **Size**: ~55MB
- **Contains**: EN/VI embeddings, cosine similarities, metadata
- **Status**: Generated during quality analysis (can be regenerated)

## Translation Quality

- **Method**: Professional human translation using Label Studio
- **Translators**: Experienced Vietnamese translators with SQL/technical background
- **Quality assurance**: Cross-lingual semantic alignment analysis using OpenAI embeddings
- **Expected semantic similarity**: > 0.85 cosine similarity between EN/VI embeddings

## Structure of `vispider_train_2000.json`

Each sample contains:
```json
{
  "id": "train_0",
  "db_id": "concert_singer",
  "question": "How many singers do we have?",
  "vi_question": "Chúng ta có bao nhiêu ca sĩ?",
  "query": "SELECT count(*) FROM singer",
  "hardness": "easy",
  "patterns": ["count"]
}
```

## Difficulty Distribution

- **Easy**: 685 samples (34.3%)
- **Medium**: 619 samples (31.0%)
- **Hard**: 437 samples (21.9%)
- **Extra Hard**: 255 samples (12.8%)

## Pattern Coverage

Covers all major SQL patterns:
- Basic SELECT, WHERE, JOIN operations
- Aggregation (COUNT, SUM, AVG, MAX, MIN)
- GROUP BY, HAVING, ORDER BY
- Subqueries, nested queries
- Set operations (UNION, INTERSECT, EXCEPT)
- Complex multi-table joins
