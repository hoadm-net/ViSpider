# Manual Vietnamese Translations for Spider Dataset

This folder contains manually translated samples from the Spider text-to-SQL dataset.

## Files

### `label_studio_2000_samples.json`
- **Source**: Label Studio export from human translation project
- **Format**: Label Studio annotation format with metadata
- **Status**: Raw export from annotation tool

### `vispider_train_2000.json`
- **Source**: Parsed from `label_studio_2000_samples.json`
- **Format**: Clean JSON format for training/evaluation
- **Status**: Ready for use

### `vispider_embeddings.json`
- **Source**: Generated by `scripts/phase2_manual/02_compute_embeddings.py`
- **Format**: LaBSE embeddings with cosine similarities
- **Contains**: EN/VI embeddings, cosine similarities, metadata
- **Status**: Generated during quality analysis (can be regenerated)

## Translation Quality

- **Method**: Professional human translation using Label Studio
- **Translators**: Experienced Vietnamese translators with SQL/technical background
- **Quality assurance**: Cross-lingual semantic alignment using LaBSE embeddings

## Structure of `vispider_train_2000.json`

Each sample contains:
```json
{
  "id": "train_0",
  "db_id": "concert_singer",
  "question": "How many singers do we have?",
  "vi_question": "Chúng ta có bao nhiêu ca sĩ?",
  "query": "SELECT count(*) FROM singer",
  "hardness": "easy",
  "patterns": ["count"]
}
```

## Usage

To parse a new Label Studio export:
```bash
cd ViSpider
source venv/bin/activate
python3 scripts/phase2_manual/01_parse_label_studio.py
```

To re-generate embeddings:
```bash
python3 scripts/phase2_manual/02_compute_embeddings.py
```
